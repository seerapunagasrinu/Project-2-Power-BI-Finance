#Project Title:

#Sales & Financial Performance

#Description:

An end-to-end Business Intelligence project focused on monitoring and analyzing individual Sales Representative performance against set financial targets. This solution transforms raw sales data into actionable, easy-to-interpret insights 

for sales leaders and individual reps.

Key Technical Components:

Tools: Excel, Power Query, Power BI (Desktop).

Data Modeling: Implemented a Star Schema linking Fact tables (e.g., Targets, Actual) to Dimension tables (e.g., dimPeople, Calendar).

Analytics: Utilized advanced DAX functions to calculate core KPIs (YTD Variance, Target Attainment %).

Innovation: Features a Narrative Visual to provide automated, plain-language summaries of key performance trends.

Focus:

Individual Sales Rep Ranking and Performance Gap Identification.

Financial Reporting (Sales vs. Target).
